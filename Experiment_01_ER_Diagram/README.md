# Experiment 1 – ER Diagram

## Aim
Design an ER diagram for an Indian e-commerce platform.

## CO Mapping
CO1

## Description
Design an ER diagram for an Indian e-commerce platform with entities:

- Customer
- Product
- Order
- OrderItem
- Seller
- Category
- Payment
- Delivery
- Address

The ER diagram should demonstrate:

- Primary keys
- Foreign keys
- Composite keys
- Multi-valued attributes
- Weak entities
- Specialization of Product
- Participation constraints
